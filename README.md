# 🐍 Python Proyectos — FreeCodeCamp

Colección de mis proyectos de la certificación **Scientific Computing with Python** de [freeCodeCamp](https://www.freecodecamp.org/), hecha mientras aprendía Python de forma autodidacta.

## 📁 Proyectos

| Archivo | Proyecto FCC / Tema | Conceptos practicados |
|---|---|---|
| `hanoi_solver.py` | Torres de Hanoi | **Recursión**, pilas, type hints, clean code |
| `polygon_area_calculator.py` | Polygon Area Calculator | **POO y herencia** (`Square(Rectangle)`), validación de tipos, sobrecarga de `__str__` |
| `budget_app.py` | Budget App | Clases, encapsulación de `ledger`, formato de strings, gráfico de porcentajes ASCII |
| `build_a_hash_table.py` | Hash Table | Diccionarios, funciones hash con `ord()`, resolución de colisiones |
| `build_a_planet_class.py` | Planet Class | POO básica, `__init__` y métodos de instancia |
| `build_a_player_interface.py` | Player Interface | Diseño de clases, atributos y representación de objetos |
| `user_config_manager.py` | User Config Manager | Manejo de estado y configuración de usuario |

## ▶️ Ejecutar

```bash
# Requiere Python 3
python3 hanoi_solver.py
python3 polygon_area_calculator.py
```
